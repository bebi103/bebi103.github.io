Set convenient HoloViews defaults.

Called without arguments, sets default visual plotting options for HoloViews for an IPython or Jupyter notebook session. Note that the HoloViews extension must be set before calling set_defaults(). A common use case:

import holoviews as hv import bebi103 hv.extension(‘bokeh’) bebi103.hv.set_defaults()
